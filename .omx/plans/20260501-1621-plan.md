## Problem

Consensus는 한·미 주식을 3개 구루 전략(CANSLIM·Piotroski·Magic Formula)으로
점수화·순위화하는 freemium SaaS다. 현재 3가지 핵심 문제가 있다:

1. **속도**: 신규 종목 hydration 18초+ (yfinance/KIS 순차 API 호출)
2. **전략 미완성**: Minervini → Magic Formula 교체, 3전략 기준 일부 누락
3. **디자인 미달**: 프로토타입 수준에 비해 실제 UI 품질 부족

타겟: 40대 직장인, 돈 있고 투자 시작 못한 사람 (및 창업자 자신 같은 중급 투자자).
법적 포지셔닝: 투자정보 제공 (투자자문 아님) — 전 화면 고지 필수.

## Plan: 4개 Phase

### Phase 1 — 데이터 파이프라인 재구축 (속도 18초 → 3초)

**근본 원인**: 신규 종목 hydration이 on-demand 동기 호출
- `run_us_price_ingestion(days=365)` + `run_market_fundamentals_ingestion(years=5)` 순차 실행
- 외부 API(yfinance, KIS) 호출 latency 합산 → 18초

**해결 방향**: Pre-compute → Serve from DB

```
Task 1.1: 야간 배치 스케줄러 구축
  - Celery Beat으로 매일 장 마감 후 전 종목 일괄 hydration
  - US: 동부시간 16:30 이후, KR: 한국시간 15:30 이후
  - 처음 방문한 종목만 on-demand (이후엔 배치로 커버)

Task 1.2: On-demand hydration 응답 개선
  - 신규 종목 첫 요청: 즉시 "수집 중" 상태 반환 (polling UI)
  - 백그라운드에서 병렬 fetch (가격 + 재무 동시)
  - asyncio.gather()로 병렬화: yfinance와 fundamental 동시 실행

Task 1.3: Redis 캐시 레이어 추가 (Railway Redis)
  - 랭킹 결과: 5분 TTL (현재 in-memory TtlCache → Redis로 업그레이드)
  - 종목 상세: 1시간 TTL
  - 배치 완료 시 캐시 무효화

Task 1.4: DB 인덱스 점검
  - consensus_scores: score_date, market, conviction 복합 인덱스 확인
  - price: (instrument_id, date) 복합 인덱스 확인
  - strategy_scores: (instrument_id, score_date) 확인
```

**완료 기준**: 랭킹 첫 로드 3초 이내, 신규 종목 on-demand 5초 이내 + polling UI

### Phase 2 — Magic Formula 전략 추가 + Minervini 제거

```
Task 2.1: Magic Formula 엔진 구현
  위치: backend/app/services/strategies/magic_formula/engine.py
  
  계산:
    ROIC = EBIT / (Net Working Capital + Net Fixed Assets)
    EY   = EBIT / Enterprise Value (= Market Cap + Debt - Cash)
  
  데이터 소스:
    - EBIT: 기존 fundamental 테이블 (영업이익)
    - Market Cap: price × shares_outstanding
    - Debt, Cash: balance sheet (기존 annual_reports)
  
  스코어링: 유니버스 내 ROIC 순위 + EY 순위 합산 (낮을수록 우수)
  → 합산 순위를 0-100 점수로 정규화

Task 2.2: Minervini → Magic Formula 교체
  - scoring_compute.py에서 Minervini import 제거
  - Magic Formula 추가
  - consensus_scores 가중치 업데이트: CANSLIM 40% + Piotroski 30% + Magic Formula 30%
  - DB 마이그레이션: strategy_scores 기존 minervini 데이터 보존 (하위 호환)

Task 2.3: 전략 상세 설명 데이터 추가
  - 각 기준 항목의 한국어 설명 추가
  - "왜 이 점수인가" 설명 API 엔드포인트
  - 초보 친화적: "EPS가 전분기 대비 25% 이상 성장했어요" 식 자연어
```
